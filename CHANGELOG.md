# Changelog

All notable changes are documented in this file.

## 1.0.8 - 2026-10-08

- Added a unified customer inbox in Message Hub Studio
- Added sender names for outbound customer messages
- Added launcher preview, custom color, and four launcher sizes
- Replaced separate desktop/mobile offsets with one saved launcher offset
- Added runtime launcher position, visibility, and z-index APIs
- Added detailed widget API documentation in Studio and the integration guide

## 1.0.0 - 2026-10-07

- Initial public self-hosted release
- Single-process Next.js application with SQLite
- Embeddable widget, realtime replies, signed webhooks, and file attachments
- Eight UI languages
- Docker deployment and operational documentation

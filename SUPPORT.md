# Support

Message Hub is community-supported self-hosted software and has no SLA.

- Use GitHub Issues for reproducible bugs.
- Use GitHub Discussions for setup questions, deployment experiences, and ideas.
- Use private vulnerability reporting for security issues.

Before opening an issue:

1. Read [README.md](README.md), [docs/integration.md](docs/integration.md), and [docs/deploy.md](docs/deploy.md).
2. Check existing issues.
3. Run the latest release.
4. Remove secrets and personal data from logs and examples.

Operational incidents in a self-hosted deployment remain the responsibility of its operator.
